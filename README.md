
# TaskFlow — Android Productivity App

TaskFlow is a native Android task management application built with Kotlin and Jetpack Compose. It is designed to help users organize tasks and monitor their daily productivity.

## Features

- Create and manage tasks
- Mark tasks as completed
- Organize tasks by category and priority
- Track task completion progress


> Project status: Personal learning project under development.
> Feature availability should be verified against the current implementation.

## Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio
- Material 3

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Run the app on an Android emulator or compatible device.
